# Authority, status and evidence

## Authority order

1. Explicit user instruction.
2. Explicitly approved canon.
3. Story Bible.
4. Approved previous scenes.
5. Story architecture.
6. Scene briefs.
7. Current drafts.
8. AI assumptions.

Check scope, revision and approval evidence before comparing authority. A speculative question is not an instruction to replace canon. Lower-ranked contradictions are conflicts to correct or propose, not reasons to overwrite. Equally authoritative conflicting sources require a narrative-owner decision. Newer text without approval does not win by date alone.

Approved facts outside the bible are pending synchronization: cite approval and surface the discrepancy; do not silently change the baseline during QUERY. If an approved scene and bible diverge, report the authoritative fact and stale bible entry separately. Substantial replacements still need retcon impact review.

## Independent dimensions

| Dimension | Values / meaning |
| --- | --- |
| Canon status | CANON confirmed truth; PROPOSED candidate; DRAFT in progress; DEPRECATED intentionally replaced; REJECTED explicitly rejected; UNKNOWN not established |
| Confidence | CONFIRMED explicit evidence; INFERRED implication; PROPOSED suggestion; UNKNOWN absent evidence |
| Occurrence | PLANNED; CONDITIONAL authored outcome; OCCURRED in a specified path/history |
| Visibility | AUTHOR_ONLY secret; PLAYER_SAFE; audience-specific knowledge |
| Scope | Universal world rule, branch predicate, timeline interval or player-history ID |

Confidence is not approval. Inferred facts cannot become CANON unless explicitly approved. Entity status does not make every field canon: mixed-status fields need their own metadata.

Use stable fact IDs when claims need independent provenance. Every canon assertion has source/revision, approval evidence, valid time and branch scope. FALSE, UNKNOWN, not applicable and explicit `none` are different values.

## Conflicts

Report kind (`CANON CONFLICT` / `WORLD RULE CONFLICT`), fact IDs, old/new claims, citations, branch/time overlap, severity and downstream scope. Lies, false beliefs and incompatible branch outcomes are not themselves contradictions; check perspective and guards first. Missing evidence is a gap, not proof of falsehood.

Example: canon establishes a lost left eye; a later draft uses that eye to aim. Keep canon; propose correcting the draft. An explicit request to restore sight is a RETCON candidate requiring impact analysis, not permission to invent an exception.
