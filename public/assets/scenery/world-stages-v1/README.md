# Bộ cảnh thế giới v1

Asset nội bộ tạo bằng công cụ ImageGen tích hợp ngày 2026-10-03, dùng nền `Rừng Trúc U Minh v1` làm tham chiếu phong cách. Không dùng asset bên ngoài.

- `remote-countryside.webp`: vùng quê hẻo lánh, 1536×1024.
- `ancient-forest.webp`: rừng cổ thụ, 1536×1024.
- `bustling-capital.webp`: kinh thành, 2172×724.
- `grand-shop-interior.webp`: nội thất cửa hàng lớn, 1536×1024.
- `cultivation-sect-palace.webp`: cung điện môn phái tu tiên, 1536×1024.
- `layered-mountains.webp`: núi đồi trùng trùng, 1881×836.

Ảnh không chứa nhân vật, UI hoặc chữ và có dải nền phía dưới dành cho gameplay đi ngang. Renderer cần tắt smoothing và hiển thị bằng `image-rendering: pixelated`. Ảnh nguồn PNG và prompt được lưu tại `art/scenery/world-stages-v1/`.
