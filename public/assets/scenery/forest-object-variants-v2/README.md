# Biến thể vật thể Rừng Trúc v2

Asset nội bộ tạo bằng ImageGen tích hợp ngày 2026-10-05; không dùng asset bên ngoài.

- `variants-atlas.webp`: atlas lossless 4×2, ô 256px.
- Hàng trên gồm bốn biến thể đá có va chạm và mặt đứng được.
- Hàng dưới gồm sỏi, dương xỉ, măng trúc và đèn đá vỡ chỉ dùng trang trí, không tham gia va chạm.
- Renderer dùng crop alpha chặt cho đá để pixel đầu tiên của mặt đá trùng đúng đỉnh collider.
- Ảnh nguồn và prompt nằm tại `art/scenery/forest-object-variants-v2/`.
